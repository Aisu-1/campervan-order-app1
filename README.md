# Camper Kitchen Ordering System 🚐🍔

キッチンカー（フードトラック）や小規模店舗向けの、リアルタイム注文・管理システムです。
顧客は自身のスマートフォン（QRコード）からメニューを閲覧・注文でき、スタッフは管理画面で注文の状況をリアルタイムに一元管理できます。

---

## 🌟 主な機能

### 📱 顧客用画面
- **モバイルフレンドリー**: 直感的なメニュー閲覧とカテゴリフィルタ。
- **リアルタイム追跡**: 注文のステータス（受付済 → 調理中 → できあがり）をリアルタイムに更新。
- **履歴管理**: ブラウザのローカルストレージを利用し、過去の注文を再確認可能。
- **カスタマイズ**: カート内での数量変更や詳細確認。

### 👨‍🍳 スタッフ用管理画面
- **セキュアなアクセス**: 環境変数で設定可能なPINコードによるアクセス制限。
- **注文管理**: 受信した注文をリスト表示。ステータス変更はボタン一つで完了。
- **プッシュ通知**: 新規注文受信時に音で通知し、見逃しを防止。
- **在庫管理**: 売り切れ商品の表示・非表示を即座にスイッチ。
- **履歴表示**: 完了した注文を履歴として閲覧可能。

### 📊 外部連携・拡張
- **Googleスプレッドシート連携**: 売上データを自動的に記録（GAS経由）。
- **PDFレポート**: 日次などの売上集計をPDFで出力可能。

## ⚙️ 事前準備（環境変数の設定）

本システムを正しく動作させるために、以下の環境変数を設定してください。ローカル開発時は `.env` ファイル、本番環境（Fly.io等）では環境設定パネルから登録します。

| 変数名 | 説明 | 例 |
| :--- | :--- | :--- |
| `STAFF_PIN` | スタッフ画面へのログイン用PIN（数字） | `1234` |
| `GAS_URL` | 売上記録用 Google Apps Script のURL | `https://script.google.com/...` |
| `VITE_API_URL` | (開発時) フロントエンドが接続するバックエンドURL | `http://localhost:3001` |

## 🚀 セットアップと起動方法

### 1. 依存関係のインストール

プロジェクトのルートディレクトリで、サーバーとクライアントそれぞれのパッケージをインストールします。

```bash
# サーバー側
cd server
npm install

# クライアント側
cd ../client
npm install
```

### 2. アプリケーションの起動

開発環境では、2つのターミナル（またはプロセス）を起動します。

**サーバー (Backend):**
```bash
cd server
node index.js
```

**フロントエンド (Frontend):**
```bash
cd client
npm run dev
```

### 3. アクセス

- **顧客用画面**: `http://localhost:5173/`
- **スタッフ用管理画面**: `http://localhost:5173/staff`

## 🛠 カスタマイズと管理

### 注文履歴のリセット
- **ローカル環境**: `server/campervan.db` ファイルを削除してサーバーを再起動すると、データベースが初期化されます。
- **本番環境 (Fly.io)**: 
  ```bash
  fly ssh console -C "rm /data/campervan.db"
  fly apps restart
  ```

### レポート用フォントのセットアップ
PDFレポート出力には日本語フォントが必要です。ライセンスの関係上、初期状態では含まれていません。以下のコマンドでダウンロードできます。
```bash
node download_font.js
```
